# Cálculo Trivial 1.0.5

Atualização focada em melhorias pedagógicas e de estabilidade.

## Principais mudanças

- diagnóstico pedagógico ampliado para os seis módulos principais;
- recomendações de revisão baseadas em evidências de prática e teste final;
- priorização refinada quando existem múltiplas dificuldades;
- navegação corrigida para levar o estudante ao módulo adequado de revisão;
- melhorias internas de testes, consistência e documentação do projeto.

## Observações

Esta versão preserva autenticação, progresso, sincronização, Premium, RevenueCat e estrutura atual do Firebase/Firestore.
