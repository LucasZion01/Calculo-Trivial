# Feedback progressivo — V1

Escopo desta primeira iteração:

- manter o comportamento direto para respostas corretas;
- para respostas incorretas, ocultar inicialmente a resposta correta e a explicação completa;
- revelar ajuda em etapas: primeira pista, próximo passo e, por fim, solução;
- reutilizar a habilidade (`skill`) já existente no exercício como contexto da primeira pista;
- não alterar diagnóstico pedagógico, pontuação, progresso, Firebase, RevenueCat ou bancos de questões;
- manter suporte a português e inglês;
- adicionar testes de widget garantindo que a solução não apareça antes da revelação explícita.

Esta V1 cria o fluxo progressivo compartilhado. Pistas matemáticas específicas por exercício permanecem para uma iteração posterior.
